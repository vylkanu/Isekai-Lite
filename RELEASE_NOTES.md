# Isekai Pulse Lite v0.1.3 — Вкладка Чекпоинты

Новый раздел **«Чек-поинты»** показывает, какое здание выгоднее улучшать до следующего порога.

### Что добавлено

- Текущий уровень → следующий чек-поинт, стоимость перехода и сколько золота ещё нужно накопить.
- Время накопления по текущему балансу и общему доходу из запущенной игры.
- Действующие скидки на улучшения, включая назначенных питомцев, без повторного начисления бонусов.
- Оценка дохода после достижения цели, прибавка золота в секунду и процент прироста.
- **Полезность 0–100**: прирост дохода на потраченное золото относительно лучшего текущего варианта.
- Окупаемость полной стоимости перехода, выделение лучшей цели и сортировки по полезности, приросту, цене и времени.
- Фильтрация полученных напарниц и питомцев по спискам владения; служебные записи не добавляются в коллекцию.

Прогноз сохраняет текущие бонусы и расстановку. Новые назначения, изменение навыков и будущие серверные эффекты могут изменить результат. Окупаемость считается по дополнительному доходу после достижения цели, без прибыли промежуточных уровней. Если базовая формула не согласуется с текущими данными, прогноз скрывается.

### Первый запуск

Скачайте **Isekai-Lite-Windows-x64.zip**, распакуйте целиком и запустите **Isekai_Pulse_Lite.exe** или **Start_Lite.bat**. Python и зависимости уже включены. Для обычного запуска не используйте автоматический архив GitHub **Source code**.

### Обновление v0.1.0 / v0.1.1 / v0.1.2

1. В панели нажмите **«Завершить Lite»**.
2. Распакуйте **Isekai-Pulse-Lite-v0.1.3-Update.zip** прямо в существующую папку Lite с заменой файлов. `web`, `catalog` и `runtime_bridge` должны объединиться с одноимёнными папками.
3. Запустите Lite снова. Запустите игру, откройте деревню и нажмите **«Обновить из игры»**.
4. Обновите вкладку браузера через **Ctrl+F5** и откройте **«Чек-поинты»**.

Апдейт накопительный и требует уже установленного полного комплекта. Сохраняются выбор сохранения, тема, журнал, настройки и извлечённые модели. Порт остаётся **8767**; оба имени EXE поддерживаются. Файлы игры и сохранения не изменяются.

**Isekai-Lite-Source.zip** — полный исходный комплект без переносного runtime. **SHA256SUMS.txt** содержит контрольные суммы трёх архивов; **UPDATE_MANIFEST.json** внутри комплектов — список файлов накопительного апдейта с SHA-256.

Архивы основаны на официальном v0.1.2, контрольные суммы входных файлов сверены. Поддержка чтения экономики привязана к проверенной сборке игры; при её изменении требуется проверка совместимости. В чистом комплекте нет личных данных аккаунта, готовых моделей и журналов.
