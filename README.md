# Isekai Pulse Lite

Переносная панель для **Isekai: Waifu Overlord** на Windows 10/11 x64.

## Скачать и запустить

**[Скачать Isekai Pulse Lite для Windows x64](https://github.com/vylkanu/Isekai-Lite/releases/latest/download/Isekai-Lite-Windows-x64.zip)**

1. Откройте **Releases** в этом репозитории.
2. Скачайте **Isekai-Lite-Windows-x64.zip** из списка Assets.
3. Распакуйте архив целиком в отдельную папку с правом записи.
4. Запустите **Isekai_Pulse_Lite.exe**. Резервный запуск — **Start_Lite.bat**.
5. Панель откроется по адресу http://127.0.0.1:8767.

Python и зависимости включены. Устанавливать Python или Node.js не нужно.
Для EXE и извлечения моделей используется .NET Framework Windows.
Для запуска нужен именно **Isekai-Lite-Windows-x64.zip**, а не автоматический **Source code (zip)**.

## Обновление v0.1.3 — Вкладка Чекпоинты

**[Скачать отдельный апдейт v0.1.3](https://github.com/vylkanu/Isekai-Lite/releases/download/v0.1.3/Isekai-Pulse-Lite-v0.1.3-Update.zip)**

Для установленной v0.1.0–v0.1.2: нажмите **«Завершить Lite»**, распакуйте Update
прямо в существующую папку с заменой файлов и запустите панель снова.
Затем откройте деревню в игре, нажмите **«Обновить из игры»** и обновите браузер
через **Ctrl+F5**. Личные настройки, журнал и модели сохраняются.
Апдейт требует полный комплект; Python/runtime повторно скачивать не нужно.

Новая вкладка **«Чек-поинты»**: стоимость перехода, скидки назначенных питомцев,
время накопления, оценка прироста дохода, полезность 0–100 и окупаемость.
Прогноз предполагает неизменные бонусы и расстановку. Подробности — в релизе.

## Первое обновление

Запустите установленную игру и откройте деревню. В панели нажмите
**«Обновить из игры»** под сменой темы. Дождитесь подготовки изображений.
Игра определяется через запущенный процесс и библиотеки Steam. Если поиск
не сработал, выберите её EXE в настройках и сохраните путь.

Если найдено несколько сохранений, откройте **Настройки → Сохранение аккаунта →
Найти сохранения**, выберите нужный файл по имени и дате изменения и нажмите
**Сохранить выбор**, затем **«Обновить из игры»**. Автоматический выбор работает
только при одном корректном сохранении. При смене выбора наблюдение призывов
подключается заново вручную. Сохранения не удаляются и не изменяются.

В комплекте нет аккаунта, истории призывов или готовых моделей персонажей.
Модели, портреты и чиби извлекаются из установленной игры только для полученных
напарниц. Повторная проверка ресурсов зависит от версии игры, таблиц и состава коллекции.

## Возможности

- Полученные напарницы: модели, чиби, судьба, навыки и производственные таланты.
- Здания, доход и справочный совет по размещению.
- Чек-поинты: стоимость со скидками, время накопления, прирост дохода, полезность и окупаемость.
- Древо навыков и полученные питомцы.
- Журнал новых призывов после включения наблюдения.
- Калькулятор молотков и справочный подбор напарниц.
- Светлая и тёмная темы.

Панель читает данные. Она не изменяет сохранение, ресурсы, уровни и размещение в игре.
После обновления игры модули чтения могут потребовать проверки совместимости.

## Перенос и локальные данные

Переносите всю папку, включая **runtime** и **tools**.
После обновления в ней сохраняются данные вашего аккаунта и извлечённые изображения.
Другим пользователям передавайте чистый архив из Releases.
Для завершения сервера нажмите **«Завершить Lite»**: закрытие вкладки его не останавливает.

## Разработка

Карта проекта — `docs/project-context.md`, проверки — `docs/validation.md`.
Полные исходники с необходимыми справочными ресурсами доступны в
**Isekai-Lite-Source.zip** в Assets релиза, отдельно от переносного runtime.
Автоматические архивы **Source code** содержат только файлы репозитория.
Лицензионные уведомления включённых зависимостей сохранены в поставке.
Isekai Pulse Lite — неофициальная панель. Название игры и её материалы принадлежат правообладателям.
